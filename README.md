# Week 5, Spring 2026: Aquatic invertebrates

## General information

This repository contains data and code to explore patterns in aquatic invertebrate abundance at North Campus Open Space.

To work with the code in this repository, you will need the following packages:

```
library(tidyverse)
library(here)
library(janitor)
library(snakecase)
library(scales)
library(readxl)
library(naniar)
library(patchwork)
library(wesanderson)
```
